# Stale Page Radar for Confluence: End User Privacy Policy

Effective 2026-10-01.

Stale Page Radar runs inside your Atlassian site as a Forge app. When an administrator runs a report, the app reads page titles, space keys and version dates through that administrator's own Confluence permissions. It stores only the most recent report in Forge app storage, which lives on Atlassian's infrastructure inside your site. It sends nothing to any other service, collects no personal data beyond what Confluence already shows the administrator, and uses no analytics. Uninstalling the app deletes its storage.
